# Khalid Ghazwani — Portfolio

Personal portfolio website showcasing software engineering projects, AI / deep learning architectures, and full-stack solutions.

## Tech Stack

- **Framework / Core:** HTML5, Modern Vanilla JS, Vite
- **Styling:** Tailwind CSS, Custom Design System
- **Fonts:** Plus Jakarta Sans, Syne, JetBrains Mono
- **Deployment:** GitHub Pages / Vercel

## Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run dev server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Preview build:**
   ```bash
   npm run preview
   ```
